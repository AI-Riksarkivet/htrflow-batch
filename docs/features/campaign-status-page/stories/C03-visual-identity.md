# C03 · Riksarkivet visual identity

**Story.** As the product owner, I want the status page to look like a Riksarkivet tool — the agency's colours, typography and logo, applied through the existing shared theme — so that it can be shown to colleagues and management as ours.

## Why it matters

The page uses a neutral theme built for contrast and consistency (B32). Once it is the face of the batch system it should carry the agency's identity, without undoing the accessibility work.

## What this delivers

- The shared theme tokens (colours, type scale, spacing) mapped to the Riksarkivet visual identity; logo and favicon; the viewer's chrome (UV4 at `/uv.html`) aligned where its configuration allows.
- Contrast re-verified after the change (C02) — brand colours that fail AA are adjusted, not exempted.

## Done when

- [ ] The page and the viewer use the agency identity; every AA contrast check still passes; screenshots are in the docs.
