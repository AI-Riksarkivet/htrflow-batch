# Icons used in the slides

- `icon-kubernetes.svg`, `icon-kyverno.svg`, `icon-argo.svg`, `icon-helm.svg`:
  the projects' own icons from the CNCF artwork repository
  (github.com/cncf/artwork), used to name those projects under the CNCF
  trademark guidelines.
- `icon-etcd.svg`: the etcd icon from the CNCF artwork repository.
- Pod, Job and node icons inside the hand-drawn diagrams (`docs/slides/diagrams/icons/`): the
  Kubernetes Icons Set (github.com/kubernetes/community, `icons/`), under
  Apache-2.0 or CC-BY-4.0.
- `icon-kueue.svg`: the Kueue logo from its repository
  (github.com/kubernetes-sigs/kueue, `site/static/images/logo.svg`).
- `icon-wrapper.svg`, `icon-converter.svg`, `icon-web.svg`, `icon-charts.svg`,
  `icon-htrflow.svg`, `icon-viewer.svg`, `icon-gpu.svg`, `icon-s3.svg`, `icon-git.svg`,
  `icon-package.svg`, `icon-package-check.svg`, `icon-file-badge.svg`, and the
  line icons inside the hand-drawn diagrams: Lucide
  icons (lucide.dev, ISC licence), recoloured. Plain icons stand in where a
  project has no SVG logo or its trademark rules do not suit slides.
